皮肤：

🎯优选区

可单选或多选，默认 IPv4

端口非 443 时，测试与输出都带端口，如 6.6.6.6:2053#JP（IPv6 写作 [2606:4700::1]:2053#JP）；443 不写端口。下载测速只测延迟最低的一批（最多 60 个），按速度从高到低排序，开启后耗时更长。

🔗节点区

网段很多时，先随机选出若干网段，再由程序在每个网段内随机生成 IP 测试。TLS 证书与域名验证始终开启，只统计真正握手成功的结果。

☁️上传区

GitHub（通过 GitHub API 写入，无需安装 git）

没有仓库？登录 GitHub → New repository → 建一个仓库；再到 Settings → Developer settings → Fine-grained tokens，只授权该仓库的 Contents 读写权限。

文件名 · 后缀 · 写入个数（0=全部；少于总数时按文件轮询分配）。后缀以 # 开头，# 后可用英文、中文、emoji 等，如 #SG、#优选域名、#JP_域名、#🇸🇬。每次上传前会先读取原文件并复测其中的 IP / 域名，剔除失效项后与新结果合并，文件名和路径不变。
SFTP（服务器已装好网站或 WordPress 即可；路径填服务器上的真实绝对路径）
下载地址形如 https://domain.com/data/ipchosen.txt 或 https://domain.com/wp-content/uploads/2026/01/ipchosen.txt，前缀须与上面的服务器路径对应。SFTP 首次连接不校验服务器主机密钥，请只连自己的服务器；安卓版暂不支持 SFTP。

⏰自动运行

保存后程序运行期间按设定自动筛选并上传，完成后发送通知。请先填好优选 / 节点 / 上传信息再保存；间隔从保存时刻开始计时。自动运行时同样会提示代理风险。
